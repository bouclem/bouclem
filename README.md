## Projects

### [VoidGPT / VGPT](https://github.com/bouclem)
Custom LLM architecture combining Mamba state space models with Mixture of Experts. Two variants — pico (~102M params) and nano (~1.5B params). Research-phase, experimental.

### [vdx](https://voidwarelang.xyz)
A compiled, statically typed programming language with a self-hosting roadmap. Inspired by Java, C++, and Rust. Distributed as a Windows installer (`.msi`). Currently at v0.0.8.

### [VPU — Voidware Processing Unit](https://github.com/bouclem)
Custom AI inference and training chip design. Not a GPU — purpose-built for neural workloads. Two variants: VPU-T (training) and VPU-I (inference). Designed around a hybrid Systolic Array + SSM Unit + MoE Router architecture. Open-source stack: Amaranth HDL → Yosys → OpenROAD.

### [VoidMC](https://github.com/bouclem/VoidMC)
A Minecraft mod loader and modding API built from scratch. An alternative to Fabric, Forge, and NeoForge with additional developer-facing features.

### OS from scratch *(in progress)*
A bare-metal operating system — bootloader, kernel, and drivers written in ASM/C, targeting x86_64.
